# ERA — Entity Representative Agent

> **团队协作沟通框架:每个成员由自己的 AI agent 代言。**
> agent 是**放大器**(amplifier)——把人的真实想法和分歧翻译、放大、标注出处地暴露出来;
> **不是代理人**(proxy)——不替人决策、不替人达成共识。**决定权始终在人。**

> 📡 **本仓库是 ERA 方法论的公开同步源。**
> 各 host 的 Maestro / agent 从这里同步 ERA 方法论——公开 repo 免鉴权,任何 host 直接拉:
> `git clone https://github.com/kevinfitzroy/era.git`,之后 `git pull` 取最新。

---

## 它解决什么

团队协作的摩擦,很多出在"沟通"本身:需求说不清、分歧被和稀泥、信息层层转述后失真。

ERA 的赌注是——**别让人去学"怎么把话说好",让每个人的 agent 替他把话说清、把分歧摆明**。
人只做两件最擅长的事:**确认理解、拍板分歧**。

## 核心理念:放大,不是代理

| | **amplifier**(ERA 的选择) | **proxy**(要避免的) |
|---|---|---|
| agent 做什么 | 翻译 / 放大 / 标注出处,把真实信息和分歧暴露给人 | 替人交换信息、替人达成共识、把控流程 |
| 决定权 | **始终在人** | 外包给 agent,人只 sign-off |
| 信息出处 | 每条标注 `stated / inferred / unconfirmed` | 混在一起,分不清哪句是人真说的 |

这一条是整套方法论的北极星,所有机制都为它服务。

## 怎么运转

- **两根支柱**:人 ↔ 自己的 agent(引导、追问、**审对照确认**);agent ↔ agent(走 GitHub Issue / PR 协作)。
- **信息带出处(provenance)**:人说的、agent 推断的、还没确认的,一眼分得清。
- **强制身份认领**:agent 上岗前先认领"我代表谁",没认领不准干活,防身份漂移。
- **人直连旁路**:任何时候人想绕过 agent 直接谈,agent 让路,绝不挡在两个人中间。
- **保真度量**:agent 持续自查在"忠实放大"还是"悄悄失真",信号差时主动暴露。
- **方法论自我对抗**:`challenges/` 里固化对本框架的批评,**永不关闭**——已知弱点摊在明面上。

## 状态

**早期(v0.1)。** 方法论已成形,但**还没在真实团队里跑过一个月**——真正的考验在那里。
已知的最大风险(实施复杂度、强制力靠 agent 自觉、自评机制押在 LLM 的弱项上等)都没藏着,
摊开记在 [`challenges/`](challenges/)。欢迎用对抗的眼光读它。

## 一句话

> 不让人去学"怎么沟通",让 agent 替人补齐信息、引导对话、暴露分歧。
> 人只做两件事:**确认理解、拍板分歧**。
