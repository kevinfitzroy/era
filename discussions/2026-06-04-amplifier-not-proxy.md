# 定位北极星:agent 是 amplifier,不是 proxy — 2026-06-04

> 本篇是 ERA 的**定位锚**。后续所有方法论、模板、身份、流程的设计,都以本篇为准绳。
> 如果某处设计与本篇冲突,是那处设计错了,不是本篇。

## 一句话

> **ERA 的 agent 是 amplifier(放大器),不是 proxy(代理人)。**
> 它的职责是把**真实信息**和**真实分歧**低成本地暴露给人——翻译、放大、标注出处;
> **决定权与制衡权始终在人**,真实信息与真实分歧也**仍由人提供**。

## 为什么要专门立这篇:本意是怎么被稀释掉的

ERA 的本意一直是 amplifier。但它走过这样一条链路:

```
作者本意(amplifier)
   → 第一次跟协作者口头沟通(产生歧义)
   → 协作者的理解
   → 落成 v0.1 文档的措辞
   = 漂成了 proxy 调性("整个工作流程由 agent 把控""人只 sign-off")
```

**这恰好是本仓库 issue #1 描述的"信息衰减"的活标本**:每经一层人/agent 的重述,本意就漂一点,最后文档变成了和本意相反的东西。

更值得注意的是:把它**拉回来的不是两个 agent 自动达成一致**,而是作者看到修正版后认领"这才是我本意"。
—— 这件事本身就验证了 amplifier 的核心:**最终锚定靠人认领,agent 只负责把歧义暴露清楚。**

## proxy vs amplifier:分野

| 维度 | proxy(要避免) | amplifier(本意) |
|------|--------------|----------------|
| agent 干什么 | 替人交换信息、替人达成共识、把控工作流 | 翻译 + 放大 + 标注出处,把真实信息/分歧暴露给人 |
| 信息从哪来 | agent 之间生成、补齐 | **仍由人提供**;agent 不凭空造,只抽取+标注 |
| 分歧怎么处理 | agent 之间趋同、和稀泥 | **如实暴露**给人,人来制衡 |
| 决定权 | 外包给 agent(人只点头) | **不外包**,始终在人 |
| 人的参与 | 两端 sign-off,中间不管 | 参与更多一点,但看到的是真东西 |
| 失败模式 | 失真 + 趋同 + 责任稀释 | (代价)人要多看一眼,(收益)可信、可审计 |

一句话区分:**proxy 让你省心但不可信;amplifier 要你多看一眼但可信。ERA 选后者。**

## 用 amplifier 这把尺子重新 review:架构里的 proxy 残留

立了北极星后回头扫,v0.1 里多处仍是 proxy 思维的化石,需要逐一翻面:

- **A. `identities` 的"自主决定边界表"是 proxy 化石。** 「✅自己做/❌等主人拍板」这张**决定权清单**的存在本身,就预设了 agent 在替人做一部分决定。amplifier 下 agent 没有"能自己拍的决定",只有"把什么暴露给人"。表要从**决定权边界**改成**信息暴露边界**。

- **B. sign-off 形态错了:确认"回放" vs 审"对照"。** 现在是 agent 先消化、人对它的自然语言转述点头(proxy 的确认仪式)。amplifier 要把「原话 + 结构化 + 标注差异」并排摆出,人审的是**对照**,不是 agent 的二次创作。(issue #1 的 provenance 是字段级,这条是 sign-off 形态级。)

- **C. 没有"人直连旁路",agent 成了强制中介。** 整个架构里两个人**只能**经 agent↔agent 通信。但 background 自己说"人的关系/信任仍重要"。两个人想直接说句话,架构里没这条路——这是 proxy 式的**垄断中介**。amplifier 该是"默认 agent 降摩擦,但人随时能一键旁路、直接对话"。**(结构性缺失,最关键。)**

- **D. agent 没有"我代表不了,你们直接谈"的合法出口。** proxy 必须替你发声,所以流程里 agent 总会硬凑一个结构化输出。amplifier 的诚实要求:当 agent 没把握准确代言时,能明说"这个我吃不准"并把人拉进来,而不是编一个看似完整的 YAML。需要一个 `representability` 弃权出口。

次要的三条(一并记,后续处理):
- 流程状态机默认**推进权在 agent**(应在人);
- 方法论知识藏在 Maestro 里 **handoff 黑箱**(人看不到 agent 按什么规则替他跑);
- **没有保真度量**——无法判断 agent 在 amplify 还是 distort。
