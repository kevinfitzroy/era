## 一条完整的协作链路（提需求→开发）

```
业务人: "报表太慢了"
        │
        ▼
Agent A: 追问（哪个报表？多慢？什么时候？影响谁？）
        │
        ▼
Agent A: 整理成 YAML，回放确认
        │
        ▼
业务人: "对，就是这样"  ← Sign-off ①
        │
        ▼
Agent A: gh issue create --template feature_request.yaml
        │
        ▼
Agent B: git pull → 读到新 Issue → 评估可行性
        │
        ▼
Agent B: 在 Issue 下 comment："可以做，方案是……预计 3 天"
        │
        ▼
Agent A: 回放给业务人："技术上可行，预计 3 天"  ← 确认
        │
        ▼
Agent B: 开发 → 提 PR
        │
        ▼
Agent A + Agent B: 各自在 PR 下 comment
        │
        ├── 意见一致 → merge
        │
        └── 意见分歧大 → 技术人介入拍板  ← 仲裁 ②
                │
                ▼
Agent B: 部署 → 关 Issue
        │
        ▼
Agent A: 回放结果给业务人 → 业务人验收
```
